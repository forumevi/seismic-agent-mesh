# SEISMIC // Shielded Autonomous Agent Mesh Terminal 🛡️⚡

A privacy-preserving dApp prototype for autonomous AI agent micropayments built on **Seismic Testnet (Chain ID: 5124)**. 

Demonstrating Seismic's **Strong Shielded State** and **Off-Chain ZK Decryption** capabilities via interactive dual-console telemetry.

---

## 🌟 Key Features

- **Dual-Console Telemetry:** 
  - **Public Observer State:** Displays raw encrypted hex payloads as viewed by standard network observers and public block explorers.
  - **Authorized Agent State:** Decrypts agent metrics, tasks, and micropayment amounts using off-chain Zero-Knowledge (ZK-SNARK) verification.
- **Interactive Walkthrough Engine:** Guided 3-step dynamic workflow (`Trigger` -> `Inspect Public` -> `Toggle Key`) to showcase state isolation clearly.
- **Seismic Testnet Native Integration:** Configured with official RPC endpoints, Chain ID 5124, and direct SocialScan Explorer verification links.
